## О проекте

Личный помощник, который держит в порядке распорядок дня. Одна база, два входа: веб-интерфейс для спокойного разбора и бот в Телеграме для быстрых отметок на ходу. История переписки общая, поэтому разговор можно начать в браузере и продолжить в мессенджере.

Смысл не в том, чтобы просто записывать цифры, а в том, чтобы вечером получить внятный разбор дня и напоминание там, где обычно всё срывается.

## Возможности

- **День одной записью**: сон, подъём, тренировка, вода, расходы, учёба и заметки собираются в одну карточку даты
- **Питание**: блюда с граммовкой, подсчёт калорий и белка, кэш расчётов, чтобы одно и то же блюдо не считалось дважды
- **Задачи**: сроки, время, приоритет и повторы
- **Привычки**: отметки по дням, простые галочки и числовые цели
- **Умные напоминания**: вечерняя проверка дня, отбой и подъём, тренировочные дни по расписанию, без повторов уже отправленного
- **Наблюдения**: причины срывов и замеченные закономерности сохраняются и используются в дальнейшем разговоре
- **Статистика**: сводка по неделе, чтобы видеть динамику, а не отдельные дни

## Как устроено

```
app/
  main.py        веб-приложение, страницы и маршруты
  bot.py         разбор сообщений и пошаговые диалоги бота
  telegram.py    отправка сообщений в Телеграм
  brain.py       разбор произвольного текста в понятные действия
  reminders.py   расписание напоминаний и защита от повторов
  stats.py       сводки и подсчёты
  models.py      структура базы
  db.py          подключение и сессии
api/             точка входа для облачного размещения
setup_db.py      первичное создание таблиц
run_bot_local.py запуск бота на своей машине
```

Веб-часть на FastAPI с шаблонами Jinja, база через SQLAlchemy на PostgreSQL. Бот работает по webhook, поэтому одно приложение обслуживает и сайт, и мессенджер.

## Запуск

```bash
pip install -r requirements.txt

# переменные окружения: строка подключения к базе, токен бота, ключ сессий
cp .env.example .env

python setup_db.py     # создать таблицы
uvicorn app.main:app --reload
```

Для локальной проверки бота без публичного адреса:

```bash
python run_bot_local.py
```

## Доступ

Бот и вход из окна Телеграма пускают только владельца: номер чата и номер пользователя должны совпадать с `TELEGRAM_CHAT_ID`. Сообщения от других людей бот молча игнорирует. Пока номер не задан, бот отвечает только на `/start` и подсказывает номер чата.

Если задана переменная `TELEGRAM_WEBHOOK_SECRET`, адрес вебхука принимает запросы только с этим секретом в заголовке `X-Telegram-Bot-Api-Secret-Token`. Тот же секрет передаётся Телеграму при установке вебхука (параметр `secret_token`). Разрешены латинские буквы, цифры, `_` и `-`, до 256 символов.

## Тесты

```bash
pip install pytest
python -m pytest -q
```

Тесты проверяют доступ: чужие сообщения и нажатия кнопок не меняют данные, вход из Телеграма работает только для владельца, вебхук с неверным секретом отклоняется.
